AAL JOURNAL — WINDOWS PC EDITION

QUICK START
1. Extract this ZIP file.
2. Double-click "Install AAL Journal.bat".
3. AAL Journal will be added to the Desktop and Start Menu.

PORTABLE MODE
You can also double-click "AAL Journal.exe" directly from the extracted folder.
Keep all files in this folder together.

DATA
AAL Journal stores journal data locally in its dedicated Microsoft Edge/Chrome browser profile.
Use Settings > Export full backup regularly.

NOTIFICATIONS
Open Settings > Automatic time and date notifications.
Turn notifications on and allow Windows/Edge notification permission when prompted.
Scheduled reminders run while AAL Journal is open.

UNINSTALL
Run "Uninstall AAL Journal.ps1" from the installed folder if needed.
Your journal profile is preserved to avoid accidental data loss.
